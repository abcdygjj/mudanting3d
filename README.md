# 牡丹亭 · 三维戏台（纸影版）

汤显祖《牡丹亭》的互动叙事改编，在原有五出剧情、谜题与结局之上，加了一层可轻微环绕的三维“戏台”。

- 场景：沿用项目提供的四幅工笔淡彩场景，作为舞台绘景。
- 人物：低多边形网格做成墨色/纸白剪影，立在绘景之前；对白仍用原立绘，保证辨识。
- 镜头：可左右轻拖、滚轮推近；人物与绘景之间产生视差，像一座纸影戏台。
- 叙事、选择、谜题、札记、导读、存档全部沿用原版。

> 这是“纸影戏台”式的三维化：人物与镜头是三维的，场景仍是原画绘景。若需要全三维网格场景，可在后续版本继续替换。

## 运行

双击 `index.html` 即可（无需构建、无外部依赖）；也可用任意静态服务器。

在线：<https://abcdygjj.github.io/mudanting3d/>

原二维版：<https://abcdygjj.github.io/mudanting/>

## 操作

- 点击／空格／回车：推进对白
- 数字键 1–3：选择
- 拖动画面：轻微环绕；滚轮：推拉镜头
- L：第四章提灯
- 右上「导 / 记 / 音 / 设」：导读、札记、声音、设置
